# MiniMax H3 创作套件（minimax-h3-studio）

将 MiniMax H3 官方的 9 个技能整合为一个中文创作入口。从一句故事创意、一张产品图或一段音乐出发，按需求生成提示词、角色设定、分镜和制作方案，适用于动画、广告、科普、音乐与游戏开场等视频创作。

**提示词全中文 · 角色独立描述 · 九种创作模式 · 支持跨平台移植**

## 技能包内容

| 编号 | 创作模式 | 可以完成什么 |
| --- | --- | --- |
| 01 | H3 提示词编写 | 整理文生视频、首帧、首尾帧、尾帧和全能参考五种模式的提示词，包含官方基础与参考指南 |
| 02 | 3D 动画短片 | 从故事发展角色与场景，编排连续镜头、文字分镜和逐镜提示词，提供合成与质检流程 |
| 03 | 极简产品广告 | 围绕商品外观和卖点，设计产品锚定图、简洁文案、镜头运动与卡点节奏 |
| 04 | 品牌宣传短片 | 根据品牌资料规划功能展示、使用场景和行动号召，整理素材来源与制作方案 |
| 05 | 音乐 MV 与歌词动效 | 组织歌词时间轴、节拍、文字包装和多镜头衔接，保持全片主音轨一致 |
| 06 | 双人游戏开场 | 设计双角色形象、菜单确认图、按钮交互和游戏开场动画 |
| 07 | 纸艺定格科普 | 将知识点转为纸偶、分层纸雕、微缩布景和立体书式讲解分镜 |
| 08 | 纸拼贴讲解动画 | 用纸片、半调图像和视觉隐喻表现观点与知识，规划停格运动和触感音效 |
| 09 | 手绘实拍融合 | 设计发光手绘与真实空间的接触、连续变形、逃跑和手持追拍镜头 |

## 输出特点

- **全中文提示词**：正文、结构标题和镜头描述统一中文，用户指定的外语台词及锁定原文保持不变。
- **角色方便修改**：每个角色单独描述外形、服装、配色与识别特征；分镜通过角色名称引用，修改时同步检查动作和声音。
- **按需交付**：只要提示词就直接给提示词，需要完整方案时再展开角色、场景、分镜及制作流程。
- **模型选择明确**：默认 MiniMax-H3，只有用户明确选择其他模型后才切换。

视频提示词的基础中文结构为「综合多模态描述」「整体声景」「画外配乐」。这是本套件采用的中文译名，不是官方发布的中文协议；实际接口若要求英文字段或标签，应在提交时适配。详见 [中文输出规范](references/中文输出规范.md)。

## 安装与使用

将本仓库完整复制到目标智能体的技能目录，保留 `minimax-h3-studio` 文件夹名称及内部结构。Codex 的安装位置为 `~/.codex/skills/minimax-h3-studio`，安装后使用 `$minimax-h3-studio` 调用。

也可以把下面这段话发送给支持安装 Skill 的智能体：

> 请从 https://github.com/Megasu/minimax-h3-studio 安装 minimax-h3-studio，保留完整的参考文件目录。

加载后，智能体根据你的需求选择对应创作模式，只读取相关流程和模板。其他支持本地文件的智能体可从 [SKILL.md](SKILL.md) 开始，无需依赖 Codex 的界面配置。详细说明见 [移植说明](references/移植说明.md)。

## 依赖与来源

**提示词与方案**：支持读取本地文本的智能体即可使用，不需要连接视频服务。

**实际生成**：图片、视频、配音、音乐和剪辑需要目标环境提供相应工具。安装本套件不会安装模型或开通 API；没有生成服务时仍可完成前期方案和提示词。

**内容来源**：基于 [MiniMax-AI/MiniMax-H3 官方技能目录](https://github.com/MiniMax-AI/MiniMax-H3/tree/main/skills) 整理，加入中文输出、独立角色设定与跨平台适配规则。本项目为社区整合版本，非 MiniMax 官方发布；上游资料保留来源与原文，其使用和再分发遵循上游适用条款。版本记录见 [来源与版本](references/来源与版本.json)。
